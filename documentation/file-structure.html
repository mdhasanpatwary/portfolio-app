📋 Overview

The Modern Portfolio Template follows Next.js 15 App Router conventions with a well-organized structure for scalability and maintainability. This guide explains each directory and file's purpose.

Next.js 15 App Router: This template uses the new App Router (app/ directory) instead of the legacy Pages Router. Make sure you're familiar with App Router conventions.

📂 Directory Breakdown

app/ - Next.js App Router

Purpose: Contains all pages, layouts, and API routes using Next.js 15 App Router conventions.
Key Features: File-based routing, nested layouts, server components, API routes
File/Directory Purpose Type
layout.tsx Root layout component wrapping all pages Layout
page.tsx Homepage component Page
globals.css Global CSS styles and Tailwind imports Styles
api/ API routes for backend functionality API
[page]/page.tsx Individual page components Pages

components/ - UI Components

Purpose: Reusable React components organized by feature/section.
Pattern: Each directory contains related components for a specific section.
global/ - Shared components used across multiple sections (modals, buttons, etc.)
Feature directories - Components specific to each portfolio section (about/, projects/, etc.)

data/ - Content Management

Purpose: JSON files containing all website content for easy customization.
Benefit: Modify content without touching code - perfect for non-developers.
File Content Used In
banner.json Hero section content and CTA Home page banner
about.json Personal information and bio About section
projects.json Portfolio projects and details Projects section
experiences.json Work experience and achievements Experience section
skills.json Technical skills and proficiency Skills section
blog.json Blog posts and articles Blog section

config/ - Configuration

Purpose: Centralized configuration for site settings, features, and integrations.
Main File: site.config.ts - Primary configuration hub

context/ - State Management

Purpose: React Context providers for global state management.
Files: ThemeContext (dark/light mode), BlogContext (blog state)

hooks/ - Custom Hooks

Purpose: Reusable React hooks for component logic.
Example: useProjectModal for project modal state management

types/ - TypeScript Definitions

Purpose: TypeScript interfaces and type definitions for data structures.
Main File: data.ts - Types for all JSON data structures

utils/ - Utility Functions

Purpose: Helper functions and utilities used across the application.
Examples: Error logging, image processing, status components

🔧 Configuration Files

📝 Content Modification Guide

Quick Content Updates

For most content changes, you only need to edit JSON files in the data/ directory!
What to Change File to Edit Restart Required
Name, title, bio data/about.json, data/banner.json No
Contact information data/contact.json No
Projects portfolio data/projects.json No
Work experience data/experiences.json No
Skills and technologies data/skills.json No
Site configuration config/site.config.ts Yes
Environment variables .env.local Yes

Advanced Customization

Components: Modify React components in components/ for layout or functionality changes
Styles: Edit app/globals.css for global styling or component-specific CSS modules
Pages: Add new pages by creating new directories in app/ with page.tsx files

🚀 Development Workflow

File Watch & Hot Reload

The development server automatically watches these files for changes:

  • ✅ All .tsx/.ts files (instant reload)
  • ✅ JSON files in data/ directory (instant reload)
  • ✅ CSS files (instant reload)
  • ⚠️ Configuration files (.env, next.config.ts) require restart

Adding New Sections

  1. Create JSON data file in data/
  2. Create component in components/[section-name]/
  3. Add TypeScript types in types/data.ts
  4. Import and use in appropriate page
  5. Update navigation if needed
