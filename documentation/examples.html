🎯 Quick Start Examples

These examples will get you up and running quickly with common customizations.

Example 1: Personalizing Your Portfolio

Learn how to replace the demo content with your own information in under 10 minutes.

Step 1: Update Basic Information

Edit your name, title, and contact information:

// data/banner.json { "name": "Your Name", "title": "Your Professional Title | Technologies | Experience", "summary": "Your professional summary...", "image": "/your-profile-image.jpg" }

Step 2: Update About Section

Personalize your about information:

// data/about.json { "name": "Your Name", "title": "About Me", "subtitle": "Your Role | Key Technologies", "highlights": [ "Your Key Achievement 1", "Your Key Achievement 2", "Years of Experience", "Notable Accomplishment" ], "description": [ "Your first paragraph about your background...", "Your second paragraph about your goals..." ] }

Step 3: Update Contact Information

Add your real contact details:

// data/contact.json { "email": "your.email@domain.com", "phone": "+1 (555) 123-4567", "location": "Your City, Country", "socialLinks": [ { "name": "LinkedIn", "url": "https://linkedin.com/in/yourprofile", "icon": "FaLinkedin" } // ... other social links ] }
✅ Result: Your portfolio now shows your personal information instead of demo content!
Example 2: Adding Your Projects

Replace the demo projects with your own portfolio pieces.

Step 1: Prepare Project Information

Gather the following for each project:

  • Project title and description
  • Technologies used
  • Project images (recommended: 800x600px)
  • Live demo and/or GitHub links
  • Key features and challenges

Step 2: Add Project to JSON

// data/projects.json - Add to items array { "id": "unique-project-id", "title": "Your Project Name", "description": "Brief project description for the grid view.", "image": "/images/projects/your-project.jpg", "link": "https://your-project-demo.com", "category": "Web Application", // or "Mobile App", "API", etc. "technologies": [ "React", "Node.js", "MongoDB" ], "status": "live", // or "development", "completed" "longDescription": "Detailed description for the modal view...", "features": [ "Feature 1", "Feature 2", "Feature 3" ], "challenges": [ "Challenge you faced", "Another challenge" ], "solutions": [ "How you solved it", "Another solution" ], "github": "https://github.com/yourusername/project", "demo": "https://your-demo-url.com" }

Step 3: Optimize Project Images

For best performance, use optimized images:

# Recommended image specifications: - Format: WebP or JPEG - Dimensions: 800x600px (4:3 aspect ratio) - File size: Under 200KB - Store in public/images/ directory for local hosting
💡 Tip: Use consistent image dimensions and aspect ratios for a professional look.
Example 3: Customizing the Color Scheme

Change the template colors to match your personal brand.

CSS Variables
Tailwind Config
Component Styles

Method 1: CSS Custom Properties

Edit the CSS variables in app/globals.css:

/* app/globals.css */ :root { /* Light theme colors */ --primary: #your-primary-color; --secondary: #your-secondary-color; --accent: #your-accent-color; --background: #your-background-color; --text: #your-text-color; } [data-theme="dark"] { /* Dark theme colors */ --primary: #your-dark-primary; --secondary: #your-dark-secondary; --accent: #your-dark-accent; --background: #your-dark-background; --text: #your-dark-text; }

Method 2: Tailwind Configuration

Extend Tailwind's color palette:

// tailwind.config.js module.exports = { theme: { extend: { colors: { primary: { 50: '#your-color-50', 100: '#your-color-100', 500: '#your-color-500', 900: '#your-color-900', }, brand: { primary: '#your-brand-primary', secondary: '#your-brand-secondary', } } } } }

Method 3: Component-Level Styling

Apply custom styles to specific components:

// Example: Customizing the header // components/header/Header.tsx const Header = () => { return ( <header className="bg-gradient-to-r from-purple-600 to-blue-600"> {/* Your custom header styles */} </header> ) }
Example 4: Setting Up Contact Form

Configure EmailJS to receive messages from your contact form.

Step 1: Create EmailJS Account

  1. Go to EmailJS.com
  2. Create a free account
  3. Add an email service (Gmail, Outlook, etc.)
  4. Create an email template

Step 2: Configure Environment Variables

# .env.local NEXT_PUBLIC_EMAILJS_SERVICE_ID=service_xxxxxxx NEXT_PUBLIC_EMAILJS_TEMPLATE_ID=template_xxxxxxx NEXT_PUBLIC_EMAILJS_PUBLIC_KEY=xxxxxxxxxxxxxxx

Step 3: Test the Contact Form

  1. Start your development server: npm run dev
  2. Navigate to the contact page
  3. Fill out and submit the form
  4. Check your email for the test message
✅ Success: Your contact form is now fully functional!
Example 5: Adding AI Chat Widget

Enable the AI chat widget to interact with visitors about your portfolio.

Step 1: Get Google AI API Key

  1. Go to Google AI Studio
  2. Create a new API key
  3. Copy the API key

Step 2: Configure Environment Variable

# .env.local NEXT_PUBLIC_GOOGLE_API_KEY=your_google_ai_api_key_here

Step 3: Enable in Site Config

// config/site.config.ts export const siteConfig = { features: { enableAI: true, // Set to true // ... other features }, ai: { enableAI: true, googleApiKey: process.env.NEXT_PUBLIC_GOOGLE_API_KEY, }, }

Step 4: Test AI Chat

The AI chat widget will appear in the bottom-right corner. Test it by asking questions about your portfolio content.

Example 6: Creating Custom Sections

Add a new section to your portfolio (e.g., Certifications, Awards, etc.).

Step 1: Create Data File

// data/certifications.json { "title": "Certifications", "subtitle": "Professional certifications and achievements", "items": [ { "id": "1", "name": "AWS Certified Developer", "issuer": "Amazon Web Services", "date": "2023", "image": "/certifications/aws.png", "credentialUrl": "https://credential-url.com" } ] }

Step 2: Create Component

// components/certifications/Certifications.tsx import { certifications } from '@/data' export default function Certifications() { return ( <section className="py-16"> <h2 className="text-3xl font-bold mb-8">{certifications.title}</h2> <div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6"> {certifications.items.map((cert) => ( <div key={cert.id} className="bg-white p-6 rounded-lg shadow"> <h3 className="font-semibold">{cert.name}</h3> <p className="text-gray-600">{cert.issuer}</p> <p className="text-sm">{cert.date}</p> </div> ))} </div> </section> ) }

Step 3: Add Types

// types/data.ts export interface Certification { id: string name: string issuer: string date: string image?: string credentialUrl?: string } export interface CertificationsData { title: string subtitle: string items: Certification[] }

Step 4: Import in Page

// app/page.tsx or dedicated page import Certifications from '@/components/certifications/Certifications' export default function HomePage() { return ( <main> {/* Other sections */} <Certifications /> </main> ) }
