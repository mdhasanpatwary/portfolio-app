Overview

The Modern Portfolio Template includes several API endpoints for enhanced functionality. These endpoints provide dynamic content, AI chat capabilities, and RSS feeds.

Base URL

https://yourdomain.com/api

Authentication

Most endpoints are public and don't require authentication. The AI chat endpoint uses Google's Generative AI which requires an API key configured in your environment variables.

Portfolio AI Chat

POST /api/portfolio-ai

Interactive AI chat endpoint powered by Google's Generative AI. Provides context-aware responses about your portfolio content.

Request Body

{ "message": "Tell me about John's experience with React", "context": "{\"projects\": [...], \"experience\": [...]}", "language": "en" }

Parameters

Parameter Type Required Description
message string Yes User's chat message (max 2000 characters)
context string No JSON context about portfolio content
language string No Response language (en, es, fr, de, etc.)

Response

Returns a streaming text response with AI-generated content about your portfolio.

Content-Type: text/plain; charset=utf-8 X-RateLimit-Limit: 10 X-RateLimit-Remaining: 9 X-RateLimit-Reset: 1640995200 Based on the provided information, John has extensive experience with React...

Rate Limiting

This endpoint is rate-limited to 10 requests per minute per IP address.

Error Responses

Status Code Description Response
400 Bad Request {"error": "Message is required"}
429 Too Many Requests {"error": "Rate limit exceeded"}
500 Internal Server Error {"error": "Something went wrong"}

RSS Feeds

GET /rss.xml

RSS feed for blog posts and portfolio updates.

Response Format

John Doe - Portfolio Latest blog posts and portfolio updates https://yourdomain.com Blog Post Title Blog post excerpt... https://yourdomain.com/blog/post-slug Wed, 15 Nov 2023 10:00:00 GMT
GET /projects.xml

XML feed for project listings and portfolio items.

Response Format

1 E-Commerce Platform Modern e-commerce platform... React Next.js https://example.com/project

Environment Variables

Required environment variables for API functionality:

Variable Required Description
NEXT_PUBLIC_GOOGLE_API_KEY Yes* Google Generative AI API key for chat functionality
NEXT_PUBLIC_SITE_URL No Your site URL for RSS feeds and links

* Required only if AI chat feature is enabled

Usage Examples

JavaScript Fetch

// Chat with AI about portfolio const response = await fetch('/api/portfolio-ai', { method: 'POST', headers: { 'Content-Type': 'application/json', }, body: JSON.stringify({ message: 'What technologies does John specialize in?', context: JSON.stringify(portfolioData), language: 'en' }) }); // Handle streaming response const reader = response.body.getReader(); const decoder = new TextDecoder(); let result = ''; while (true) { const { done, value } = await reader.read(); if (done) break; result += decoder.decode(value); console.log(result); // Update UI with streaming text }

cURL Example

curl -X POST https://yourdomain.com/api/portfolio-ai \ -H "Content-Type: application/json" \ -d '{ "message": "Tell me about the latest projects", "language": "en" }'

SDK Integration

The template includes built-in integration with the following services:

Google Generative AI

import { GoogleGenerativeAI } from '@google/generative-ai'; const genAI = new GoogleGenerativeAI(process.env.NEXT_PUBLIC_GOOGLE_API_KEY); const model = genAI.getGenerativeModel({ model: 'gemini-pro' });

EmailJS (Contact Form)

import emailjs from '@emailjs/browser'; emailjs.sendForm( 'YOUR_SERVICE_ID', 'YOUR_TEMPLATE_ID', form, 'YOUR_PUBLIC_KEY' );
