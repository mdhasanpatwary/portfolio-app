🔧 Installation Guide

Complete setup instructions for Modern Portfolio Template

System Requirements

Before installing the template, ensure your system meets these requirements:

  • Node.js 18+ - Required for Next.js 15
  • npm 9+ or yarn 1.22+ - Package manager
  • Git - For version control (optional)
  • Code Editor - VS Code recommended
💡 Tip: You can check your Node.js version by running node --version in your terminal.

Installation Steps

Step 1: Extract Template Files

Extract the downloaded template files to your desired location:

cd your-projects-folder unzip modern-portfolio-template.zip cd modern-portfolio-template

Step 2: Install Dependencies

Install all required dependencies using npm or yarn:

# Using npm npm install # Or using yarn yarn install

This may take a few minutes depending on your internet connection.

Step 3: Environment Configuration

Copy the environment template and configure your settings:

# Copy environment template cp .env.example .env.local # Edit the file with your settings nano .env.local # or use your preferred editor
⚠️ Important: The .env.local file contains sensitive information. Never commit it to version control.

Step 4: Start Development Server

Start the development server to see your portfolio:

# Using npm npm run dev # Or using yarn yarn dev

Open http://localhost:3000 in your browser to view the template.

✅ Success! Your portfolio template is now running locally. You can start customizing it to match your needs.

Environment Variables

The template uses environment variables for optional features. Here's what each variable does:

EmailJS (Contact Form)

NEXT_PUBLIC_EMAILJS_PUBLIC_KEY=your_public_key NEXT_PUBLIC_EMAILJS_SERVICE_ID=your_service_id NEXT_PUBLIC_EMAILJS_TEMPLATE_ID=your_template_id

Required only if you want to use the contact form. Get these keys from EmailJS.

Google AI (Chat Widget)

NEXT_PUBLIC_GOOGLE_API_KEY=your_google_api_key

Required only for the AI chat widget. Get your API key from the Google Cloud Console.

Analytics (Optional)

NEXT_PUBLIC_GA_TRACKING_ID=your_google_analytics_id

For Google Analytics tracking. Vercel Analytics is automatically configured when deployed to Vercel.

Understanding the project structure will help you customize the template effectively:

modern-portfolio-template/ ├── app/ # Next.js App Router pages ├── components/ # React components ├── config/ # Site configuration ├── context/ # React Context providers ├── data/ # JSON content files ├── documentation/ # This documentation ├── hooks/ # Custom React hooks ├── public/ # Static assets ├── types/ # TypeScript type definitions ├── utils/ # Utility functions ├── .env.example # Environment template ├── next.config.ts # Next.js configuration ├── package.json # Dependencies └── tailwind.config.js # Tailwind CSS config

Common Installation Issues

Node.js Version Error

If you get an error about Node.js version:

# Check your version node --version # Install Node.js 18+ from https://nodejs.org

Permission Errors (macOS/Linux)

If you encounter permission errors during installation:

# Fix npm permissions sudo chown -R $(whoami) ~/.npm

Port Already in Use

If port 3000 is already in use:

# Use a different port npm run dev -- -p 3001
