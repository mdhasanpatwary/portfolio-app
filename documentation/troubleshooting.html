🚨 Installation Issues

Node.js Version Compatibility

Problem: Getting errors during npm install or when running development server
Solution: Ensure you're using Node.js 18+ and npm 8+
node --version # Should be 18.0.0 or higher npm --version # Should be 8.0.0 or higher

Update Node.js if needed: https://nodejs.org/

Package Installation Failures

Problem: npm install fails with dependency conflicts or network errors
Solution: Clear cache and try alternative installation methods
# Clear npm cache npm cache clean --force # Delete node_modules and package-lock.json rm -rf node_modules package-lock.json # Try installing with legacy peer deps npm install --legacy-peer-deps # Alternative: Use yarn npm install -g yarn yarn install

Permission Errors

Problem: Permission denied errors during installation
Solution: Fix npm permissions or use a Node version manager
# Option 1: Use npx to avoid global installs npx create-next-app@latest # Option 2: Use Node Version Manager (nvm) curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash nvm install 18 nvm use 18

⚙️ Build & Development Errors

TypeScript Compilation Errors

Problem: TypeScript errors preventing build or development server start
Solution: Check and fix TypeScript configuration
# Check TypeScript version npx tsc --version # Run type checking npx tsc --noEmit # Fix common type issues npm run lint

Common fixes:

  • Add missing type definitions: npm install @types/node @types/react @types/react-dom
  • Check that all imports have proper file extensions in imports
  • Verify environment variable types match your .env file

Development Server Won't Start

Problem: npm run dev fails or server doesn't start
Solution: Check port availability and configuration
# Check if port 3000 is in use lsof -ti:3000 # Kill process using port 3000 kill -9 $(lsof -ti:3000) # Start with different port npm run dev -- -p 3001 # Check for syntax errors npm run lint

Build Process Fails

Problem: npm run build fails with various errors
Solution: Common build issue fixes
# Clear Next.js cache rm -rf .next # Check for unused imports npm run lint # Build with verbose output npm run build -- --debug # Check for missing environment variables cp .env.example .env.local

🌐 Deployment Problems

Vercel Deployment Issues

Problem: Deployment fails on Vercel with build or runtime errors
Solution: Configure Vercel settings and environment variables
# Check vercel.json configuration { "framework": "nextjs", "buildCommand": "npm run build", "devCommand": "npm run dev", "installCommand": "npm install" }

Common issues:

  • Add all environment variables in Vercel dashboard
  • Check that build output size is under Vercel limits
  • Ensure all dependencies are in package.json

Static Export Issues

Problem: Static export fails or pages don't work correctly
Solution: Configure Next.js for static export
// next.config.ts const nextConfig = { output: 'export', trailingSlash: true, images: { unoptimized: true } } export default nextConfig

Environment Variables Not Working

Problem: Environment variables are undefined in production
Solution: Properly configure environment variables
Remember: Only variables prefixed with NEXT_PUBLIC_ are available in the browser.
# .env.local (for development) NEXT_PUBLIC_SITE_URL=http://localhost:3000 NEXT_PUBLIC_EMAILJS_SERVICE_ID=your_service_id # Add the same variables in your hosting platform's dashboard

⚡ Performance Issues

Slow Page Load Times

Problem: Pages load slowly or Lighthouse scores are low
Solution: Optimize images and bundles
# Analyze bundle size npm install -g @next/bundle-analyzer ANALYZE=true npm run build # Optimize images # Use next/image component for all images # Compress images before adding to public folder

Performance tips:

  • Use WebP format for images
  • Enable static optimization in next.config.ts
  • Implement lazy loading for heavy components
  • Remove unused dependencies

Large Bundle Size

Problem: JavaScript bundle is too large
Solution: Implement code splitting and tree shaking
// Use dynamic imports for heavy components const HeavyComponent = dynamic(() => import('./HeavyComponent'), { loading: () => }) // Check what's in your bundle npm run build npx @next/bundle-analyzer

📧 Contact Form Issues

EmailJS Not Working

Problem: Contact form submissions fail or don't send emails
Solution: Verify EmailJS configuration
# Check environment variables NEXT_PUBLIC_EMAILJS_SERVICE_ID=your_service_id NEXT_PUBLIC_EMAILJS_TEMPLATE_ID=your_template_id NEXT_PUBLIC_EMAILJS_PUBLIC_KEY=your_public_key

Troubleshooting steps:

  1. Verify EmailJS account is active
  2. Check service ID matches your EmailJS service
  3. Ensure template ID exists and is published
  4. Test with EmailJS dashboard first
  5. Check browser console for errors

Form Validation Issues

Problem: Form validation not working correctly
Solution: Check validation rules and error handling
// Check validation patterns in contact.json { "validation": { "nameRequired": "Name is required.", "emailRequired": "Email is required.", "emailInvalid": "Invalid email format.", "messageRequired": "Message must be at least 10 characters." } }

🤖 AI Chat Problems

AI Chat Not Responding

Problem: AI chat widget doesn't respond or shows errors
Solution: Verify Google AI configuration
# Check Google AI API key NEXT_PUBLIC_GOOGLE_API_KEY=your_google_ai_api_key # Test API key validity curl -H "Authorization: Bearer YOUR_API_KEY" \ https://generativelanguage.googleapis.com/v1/models

Common issues:

  • API key not set or incorrect
  • API quotas exceeded
  • API key doesn't have proper permissions
  • Network connectivity issues

Rate Limiting Issues

Problem: Getting rate limit errors from AI chat
Solution: Adjust rate limiting configuration
// In app/api/portfolio-ai/route.ts const RATE_LIMIT_MAX = 10; // Requests per minute const RATE_LIMIT_WINDOW_MS = 60 * 1000; // 1 minute

🎨 Styling & Theme Issues

Dark Mode Not Working

Problem: Dark mode toggle doesn't work or styles are incorrect
Solution: Check theme context and CSS variables
// Verify ThemeContext is properly wrapped // Check if localStorage is available // Ensure CSS variables are defined for both themes

Check these files:

  • context/ThemeContext.tsx - Theme state management
  • app/globals.css - CSS variables for themes
  • components/global/ThemeToggle.tsx - Toggle component

Tailwind CSS Not Working

Problem: Tailwind CSS classes not applying or not working
Solution: Check Tailwind configuration and build process
# Verify Tailwind config // tailwind.config.js module.exports = { content: [ './app/**/*.{js,ts,jsx,tsx}', './components/**/*.{js,ts,jsx,tsx}', ], // ... rest of config }

Custom CSS Not Loading

Problem: Custom CSS styles not applying
Solution: Check CSS import order and specificity
// In app/layout.tsx, ensure correct import order import './globals.css' // Should be imported in layout

📱 Mobile & Responsive Issues

Mobile Layout Problems

Problem: Layout breaks on mobile devices or specific screen sizes
Solution: Check responsive design implementation
// Use Chrome DevTools to test different screen sizes // Check for: // - Overflow issues (overflow-x: hidden) // - Fixed widths that don't scale // - Text that's too small on mobile // - Touch targets that are too small (min 44px)

Touch/Click Issues

Problem: Buttons or links not working properly on touch devices
Solution: Ensure proper touch target sizing and event handling
// Ensure minimum touch target size .button, .link { min-height: 44px; min-width: 44px; display: flex; align-items: center; justify-content: center; }
