🚀 Modern Portfolio Template

Complete documentation for your Next.js 15 portfolio template with TypeScript and Tailwind CSS v4

⚡ Quick Start

1

Extract & Install

Extract the template files and run npm install to install dependencies

npm install
2

Configure Environment

Copy .env.example to .env.local and configure your settings

cp .env.example .env.local
3

Customize Content

Edit config/site.config.ts and data/*.json files with your information

4

Start Development

Run the development server and start customizing

npm run dev
