🌐 Deployment Guide

Complete deployment instructions for your Modern Portfolio Template

🚀 Deployment Options

Your portfolio template can be deployed to various hosting platforms. Here are the most popular and recommended options:

🔷 Vercel (Recommended)

Zero-configuration deployment with automatic builds, global CDN, and serverless functions. Perfect for Next.js applications.

📦 Netlify

Static site hosting with form handling, serverless functions, and automatic deployments from Git repositories.

🌐 GitHub Pages

Free static hosting directly from your GitHub repository. Requires static export configuration.

☁️ AWS/DigitalOcean

Cloud platforms offering full control over server configuration and scaling options.

🔷 Vercel Deployment (Recommended)

Vercel offers the best experience for Next.js applications with zero configuration and optimal performance.

Step 1: Prepare Your Repository

Ensure your code is in a Git repository (GitHub, GitLab, or Bitbucket):

git init
git add .
git commit -m "Initial commit"
git remote add origin your-repository-url
git push -u origin main

Step 2: Connect to Vercel

  1. Visit vercel.com and sign up/login
  2. Click "New Project" or "Import Project"
  3. Connect your Git provider (GitHub, GitLab, Bitbucket)
  4. Select your portfolio repository
  5. Vercel automatically detects Next.js configuration

Step 3: Configure Environment Variables

Add your environment variables in the Vercel dashboard:

NEXT_PUBLIC_EMAILJS_PUBLIC_KEY=your_public_key
NEXT_PUBLIC_EMAILJS_SERVICE_ID=your_service_id
NEXT_PUBLIC_EMAILJS_TEMPLATE_ID=your_template_id
NEXT_PUBLIC_GOOGLE_API_KEY=your_google_api_key
NEXT_PUBLIC_SITE_URL=https://yourdomain.com

Step 4: Deploy

Click "Deploy" and Vercel will:

  • Install dependencies automatically
  • Build your application
  • Deploy to global CDN
  • Provide you with a live URL
🎉 Automatic Deployments: Any push to your main branch will trigger automatic redeployment!

📦 Static Export Deployment

For hosting on static platforms (GitHub Pages, Netlify, traditional web hosts), you can export your site as static files.

Step 1: Configure Static Export

Update your next.config.ts file:

/** @type {import('next').NextConfig} */
const nextConfig = {
  output: 'export',
  trailingSlash: true,
  images: {
    unoptimized: true
  },
  // Disable server-side features for static export
  experimental: {
    missingSuspenseWithCSRBailout: false,
  }
}

export default nextConfig

Step 2: Add Export Script

Add to your package.json scripts:

{
  "scripts": {
    "build": "next build",
    "export": "next build && next export",
    "deploy": "npm run export"
  }
}

Step 3: Generate Static Files

npm run export

This creates an out/ directory with all static files.

Step 4: Upload to Your Host

Upload the contents of the out/ directory to your web server's public directory.

⚠️ Static Export Limitations:
  • AI chat widget won't work (requires server-side API)
  • Contact form needs alternative setup (Formspree, Netlify Forms)
  • No server-side rendering benefits

🌐 Platform-Specific Instructions

GitHub Pages

Setup GitHub Pages Deployment

  1. Configure static export (see above)
  2. Create .github/workflows/deploy.yml:
name: Deploy to GitHub Pages

on:
  push:
    branches: [ main ]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-node@v3
        with:
          node-version: '18'
      - run: npm ci
      - run: npm run export
      - uses: peaceiris/actions-gh-pages@v3
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./out

Netlify

Netlify Configuration

Create netlify.toml in your project root:

[build]
  command = "npm run build"
  publish = ".next"

[[plugins]]
  package = "@netlify/plugin-nextjs"

[build.environment]
  NEXT_PRIVATE_TARGET = "server"

DigitalOcean App Platform

DigitalOcean Setup

  1. Connect your GitHub repository
  2. Choose "Web Service" type
  3. Set build command: npm run build
  4. Set run command: npm start
  5. Add environment variables

🚨 Troubleshooting

Build Failures

Common Issues:
  • Node.js Version: Ensure deployment platform uses Node.js 18+
  • Environment Variables: All NEXT_PUBLIC_ variables must be set
  • Import Paths: Check for case-sensitive file imports
  • Dependencies: Ensure all dependencies are in package.json

Runtime Errors

Contact Form Issues:
  • Verify EmailJS credentials are correct
  • Check CORS settings in EmailJS dashboard
  • Ensure template ID matches your EmailJS template

Performance Issues

Optimization Tips:
  • Compress images before uploading
  • Use WebP format when possible
  • Enable CDN on your hosting platform
  • Monitor Core Web Vitals in production

🎯 Custom Domain Setup

Vercel Custom Domain

Add Custom Domain

  1. Go to your Vercel project dashboard
  2. Navigate to "Settings" → "Domains"
  3. Add your domain name
  4. Configure DNS records as instructed
  5. Vercel automatically handles SSL certificates

DNS Configuration

Type: CNAME
Name: www (or @)
Value: your-vercel-deployment.vercel.app

Type: A
Name: @
Value: 76.76.19.61
💡 Pro Tip: Most domain registrars provide DNS management. Popular options include Cloudflare, Namecheap, and GoDaddy.
