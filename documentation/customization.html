🎨 Customization Guide

Make the template your own with easy customization

Quick Configuration

The fastest way to customize your portfolio is through the site configuration file:

1. Site Configuration (config/site.config.ts)

This is your main customization hub. Update the following sections:

export const siteConfig = { // Your basic information siteName: "Your Portfolio", author: { name: "Your Name", title: "Your Professional Title", email: "your@email.com", phone: "+1 (555) 123-4567", location: "Your City, Country", }, // Your social media links social: { github: "https://github.com/yourusername", linkedin: "https://linkedin.com/in/yourusername", twitter: "https://x.com/yourusername", // ... other social links }, // Toggle features on/off features: { enableAI: true, enableBlog: true, enableContact: true, // ... other feature toggles } };
💡 Pro Tip: You can disable any section you don't need by setting the corresponding feature flag to false.

Content Customization

All content is stored in JSON files in the data/ directory. Here's what each file contains:

data/ ├── about.json # Personal information and bio ├── banner.json # Hero section content ├── contact.json # Contact information and form ├── education.json # Education history ├── experiences.json # Work experience ├── footer.json # Footer content ├── header.json # Navigation menu ├── hobbies.json # Personal interests ├── projects.json # Portfolio projects ├── services.json # Services offered ├── skills.json # Technical skills └── testimonials.json # Client testimonials

Personal Information (data/about.json)

{ "name": "Your Name", "title": "About Me", "subtitle": "Your Professional Title", "highlights": [ "Your Key Achievement 1", "Your Key Achievement 2", "Your Experience Level", "Your Unique Value Proposition" ], "description": [ "Your professional bio paragraph 1...", "Your professional bio paragraph 2..." ], "traits": [ "🎯 Your Trait 1", "💡 Your Trait 2", "🧩 Your Trait 3" ], "image": { "src": "/your-profile-image.jpg", "alt": "Your Name" } }

Projects (data/projects.json)

Add your portfolio projects here:

{ "title": "My Projects", "subtitle": "Showcase of my recent work", "projects": [ { "id": 1, "title": "Project Name", "description": "Brief project description", "longDescription": "Detailed project description", "image": "/project-image.jpg", "technologies": ["React", "Next.js", "TypeScript"], "link": "https://project-url.com", "github": "https://github.com/user/repo", "category": "Web Development", "status": "live", "features": [ "Feature 1", "Feature 2", "Feature 3" ] } ] }

Skills (data/skills.json)

Organize your skills by categories:

{ "title": "Skills", "subtitle": "Technologies I use", "groups": [ { "title": "Frontend", "skills": [ { "name": "React", "level": 90, "icon": "SiReact" }, { "name": "TypeScript", "level": 85, "icon": "SiTypescript" } ] } ] }

Visual Customization

Colors and Styling

The template uses Tailwind CSS for styling. You can customize colors in several ways:

// tailwind.config.js module.exports = { theme: { extend: { colors: { primary: { 50: '#eff6ff', 500: '#3b82f6', 900: '#1e3a8a', }, secondary: { 50: '#f8fafc', 500: '#64748b', 900: '#0f172a', } } } } }

Fonts

Change fonts by updating the font imports in app/layout.tsx:

import { Inter, Roboto } from 'next/font/google' const inter = Inter({ subsets: ['latin'] }) const roboto = Roboto({ weight: ['300', '400', '500', '700'], subsets: ['latin'] })

Images

Replace placeholder images in the public/ directory:

  • /profile.webp - Main profile image
  • /profile2.webp - Secondary profile image
  • /resume.pdf - Your resume file
  • /og-image.jpg - Social media preview image
⚠️ Image Requirements:
  • Profile images: 400x400px minimum, square aspect ratio
  • Project images: 600x400px minimum, 3:2 aspect ratio
  • OG image: 1200x630px for social media previews

Feature Configuration

Contact Form Setup

To enable the contact form, you need to configure EmailJS:

  1. Create an account at EmailJS
  2. Create a service and template
  3. Add your credentials to .env.local:
NEXT_PUBLIC_EMAILJS_PUBLIC_KEY=your_public_key NEXT_PUBLIC_EMAILJS_SERVICE_ID=your_service_id NEXT_PUBLIC_EMAILJS_TEMPLATE_ID=your_template_id

AI Chat Widget Setup

To enable the AI chat widget:

  1. Get a Google Generative AI API key from Google Cloud Console
  2. Add it to your .env.local file:
NEXT_PUBLIC_GOOGLE_API_KEY=your_google_api_key

Blog Integration

The template supports Dev.to blog integration. To customize:

  1. Update your Dev.to username in the blog context
  2. Or disable the blog by setting enableBlog: false in site config

SEO Customization

Meta Tags

Update SEO settings in config/site.config.ts:

seo: { keywords: [ "your keyword 1", "your keyword 2", "your profession", "your location" ], ogImage: "/your-og-image.jpg", twitterCard: "summary_large_image", }

Sitemap

The sitemap is automatically generated. Update the configuration in next-sitemap.config.js:

module.exports = { siteUrl: 'https://yourdomain.com', generateRobotsTxt: true, changefreq: 'daily', priority: 0.7, }

Advanced Customization

Adding New Sections

To add a new section to your portfolio:

  1. Create a new component in components/your-section/
  2. Create corresponding data file in data/your-section.json
  3. Import and add to your page layout
  4. Update the navigation if needed

Custom Animations

The template uses CSS transitions and transforms. You can add custom animations:

// Example custom animation .fade-in { animation: fadeIn 0.5s ease-in-out; } @keyframes fadeIn { from { opacity: 0; transform: translateY(20px); } to { opacity: 1; transform: translateY(0); } }

Testing Your Changes

After making changes, always test your portfolio:

  1. Run npm run dev to check in development
  2. Test responsive design on different screen sizes
  3. Check dark/light mode switching
  4. Verify all links and forms work correctly
  5. Run npm run build to check for build errors
✅ Tip: Use browser developer tools to test responsiveness and performance. The template is optimized for 95+ Lighthouse scores.
