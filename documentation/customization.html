🎨 Customization Guide

Make the template your own with easy customization

Quick Configuration

The fastest way to customize your portfolio is through the site configuration file:

1. Site Configuration (config/site.config.ts)

This is your main customization hub. Update the following sections:

export const siteConfig = {
  // Your basic information
  siteName: "Your Portfolio",
  author: {
    name: "Your Name",
    title: "Your Professional Title",
    email: "your@email.com",
    phone: "+1 (555) 123-4567",
    location: "Your City, Country",
  },
  
  // Your social media links
  social: {
    github: "https://github.com/yourusername",
    linkedin: "https://linkedin.com/in/yourusername",
    twitter: "https://x.com/yourusername",
    // ... other social links
  },
  
  // Toggle features on/off
  features: {
    enableAI: true,
    enableBlog: true,
    enableContact: true,
    // ... other feature toggles
  }
};
💡 Pro Tip: You can disable any section you don't need by setting the corresponding feature flag to false.

Content Customization

All content is stored in JSON files in the data/ directory. Here's what each file contains:

data/ |-- about.json # Personal information and bio |-- banner.json # Hero section content |-- blog.json # Blog posts data |-- contact.json # Contact information and form |-- css-tips.json # CSS tips and tricks content |-- education.json # Education history |-- experiences.json # Work experience |-- faqs.json # Frequently asked questions |-- footer.json # Footer content |-- funFacts.json # Fun facts and statistics |-- header.json # Navigation menu |-- hobbies.json # Personal interests |-- index.ts # Data exports (centralized) |-- metadata.json # SEO and page metadata |-- projects.json # Portfolio projects |-- services.json # Services offered |-- skills.json # Technical skills `-- testimonials.json # Client testimonials

Visual Customization

Colors and Styling

The template uses Tailwind CSS v4 for styling. The framework includes built-in configuration without requiring a separate config file:

/* app/globals.css - Custom properties */
:root {
  --primary-50: #eff6ff;
  --primary-500: #3b82f6;
  --primary-900: #1e3a8a;
}

/* Dark mode support */
[data-theme="dark"] {
  --primary-50: #1e3a8a;
  --primary-500: #3b82f6;
  --primary-900: #eff6ff;
}

Fonts

Change fonts by updating the font imports in app/layout.tsx:

import { Inter, Roboto } from 'next/font/google'

const inter = Inter({ subsets: ['latin'] })
const roboto = Roboto({ 
  weight: ['300', '400', '500', '700'],
  subsets: ['latin'] 
})

Images

Replace placeholder images in the public/images/ directory:

  • /images/about/profile.jpg - Main profile image
  • /images/banner/hero.jpg - Hero section image
  • /images/blog/ - Blog post cover images
  • /images/projects/ - Project showcase images
  • /images/testimonials/ - Client avatar images
  • /profile.webp - Main profile image (legacy)
  • /profile2.webp - Secondary profile image (legacy)
  • /resume.pdf - Your resume file
  • /og-image.jpg - Social media preview image
⚠️ Image Requirements:
  • Profile images: 400x400px minimum, square aspect ratio
  • Project images: 600x400px minimum, 3:2 aspect ratio
  • OG image: 1200x630px for social media previews

Feature Configuration

Contact Form Setup

To enable the contact form, you need to configure EmailJS:

  1. Create an account at EmailJS
  2. Create a service and template
  3. Add your credentials to .env.local:
NEXT_PUBLIC_EMAILJS_PUBLIC_KEY=your_public_key
NEXT_PUBLIC_EMAILJS_SERVICE_ID=your_service_id
NEXT_PUBLIC_EMAILJS_TEMPLATE_ID=your_template_id

AI Chat Widget Setup

To enable the AI chat widget:

  1. Get a Google Generative AI API key from Google AI Studio
  2. Add it to your .env.local file:
NEXT_PUBLIC_GOOGLE_API_KEY=your_google_api_key

Blog Integration

The template includes a built-in blog system with markdown support. To customize:

  1. Edit data/blog.json to add your blog posts
  2. Or disable the blog by setting enableBlog: false in site config
  3. Blog posts support markdown content and are displayed with responsive cards

SEO Customization

Meta Tags

Update SEO settings in config/site.config.ts:

seo: {
  keywords: [
    "your keyword 1",
    "your keyword 2",
    "your profession",
    "your location"
  ],
  ogImage: "/your-og-image.jpg",
  twitterCard: "summary_large_image",
}

Sitemap

The sitemap is automatically generated. Update the configuration in next-sitemap.config.js:

module.exports = {
  siteUrl: 'https://yourdomain.com',
  generateRobotsTxt: true,
  changefreq: 'daily',
  priority: 0.7,
}

Advanced Customization

Adding New Sections

To add a new section to your portfolio:

  1. Create a new component in components/your-section/
  2. Create corresponding data file in data/your-section.json
  3. Import and add to your page layout
  4. Update the navigation if needed

Custom Animations

The template uses CSS transitions and transforms. You can add custom animations:

// Example custom animation
.fade-in {
  animation: fadeIn 0.5s ease-in-out;
}

@keyframes fadeIn {
  from { opacity: 0; transform: translateY(20px); }
  to { opacity: 1; transform: translateY(0); }
}

Testing Your Changes

After making changes, always test your portfolio:

  1. Run npm run dev to check in development
  2. Test responsive design on different screen sizes
  3. Check dark/light mode switching
  4. Verify all links and forms work correctly
  5. Run npm run build to check for build errors
✅ Tip: Use browser developer tools to test responsiveness and performance. The template is optimized for 95+ Lighthouse scores.

// 1. Create data/certifications.json

import { certifications } from '@/data'

export default function Certifications() {

      <div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6">

            <p className="text-gray-600">{cert.issuer}</p>
            <p className="text-sm">{cert.date}</p>
          </div>
        ))}
      </div>
    </section>
  )
}
// 3. Add to app/page.tsx
import Certifications from '@/components/certifications/Certifications'

export default function HomePage() {
  return (
